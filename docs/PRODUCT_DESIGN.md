## 1. 项目定位

- **形态**：本地运行的辅助决策工具（H5 Web 应用，手机/桌面浏览器兼容）
- **目标用户**：币安 U 本位合约交易者（短线 + 波段混合风格）
- **核心原则**：只做**决策辅助，不做自动交易**（第一版绝不自动下单）
- **解决痛点**：多币种盯盘效率、买卖点判断、风险控制、执行纪律

## 2. 交易风格与多周期框架

**短线（A）+ 波段（C）混合，核心原则：大周期定方向，小周期找时机，只做顺势单。**

| 角色 | 波段 | 短线 |
|------|------|------|
| 方向周期 | 4h（主） | 1h（主） |
| 确认周期 | 1h | 15m |
| 入场周期 | 15m | 5m |
| 持仓时长 | 几小时~几天 | 几分钟~几小时 |

## 4. 信号引擎（10 层流水线）

```
0️⃣ 市场环境层    BTC 4h 方向 + 涨跌家数比（大盘空头 → 山寨做多拦截）
1️⃣ 方向门        4h EMA55 + 价格结构(HH/HL) + MACD 零轴（前提 ADX > 25）
2️⃣ 时机扳机      15m 主导（RSI 上穿50 / 回踩EMA21 / 放量突破）
                AND 5m MACD 柱状线同向翻色 ── 双周期共振
3️⃣ 量能否决      [一票否决] 量比<1.2 且 OI 变化率<+1% → 不发信号
4️⃣ 风控刹车      费率ROC两档 + 清算距离(带宽自适应) + 盈亏比≥2
5️⃣ K线形态硬刹车  15m收盘：不破前低 + 实体>影线（防诱多/防扫损）
6️⃣ 宏观静默期     CPI/非农/FOMC 前后15分钟 → 暂停新开仓
7️⃣ 仓位与执行     市价70% + 前阳50%回撤位限价30%（45分钟未成交撤单）
8️⃣ 持仓管理       止损三段式 + 时间止损 + 相关性检查
9️⃣ 信号生命周期    有效期3根15m K线 / 冲突规则（小周期服从大周期）

═══ 平行运行 ═══
🔟 出场预警引擎    触发阈值比入场宽松（宁可早走，不可晚走）
```

### 各层详细规则

**0️⃣ 市场环境**：BTC 自身 4h 方向（EMA55 上下）+ 涨跌家数比（市场宽度）。大盘空头时，山寨做多信号直接拦截或降级为观察。

**1️⃣ 方向门**（三个方向一致才开门）：
- 4h 价格在 EMA55 之上/之下 → 大势
- 1h EMA7/EMA21 多头/空头排列 → 中期方向
- 4h MACD 零轴上方/下方 → 动能
- 前提：ADX > 25（趋势市）；ADX < 20 → 方向门关闭，仅提示震荡

**2️⃣ 时机扳机**（双周期共振，杜绝"任一即可"）：
```
扳机 = 15m 触发动作 AND 5m MACD 柱状线同向翻色
15m 触发动作分级：
  A级（最佳）: 回踩 1h/15m EMA21 附近(±0.5×ATR) 不破 + 缩量(量比<0.7) + 启动
  B级: 放量突破前高/布林上轨(量比>1.5) + 回踩确认不破
  C级(仅观察): 仅 RSI 上穿50，无量能配合
主扳机: 15m RSI 从超卖(<30)或低位(<45)向上穿越 50（空头力竭信号）
```

**3️⃣ 量能否决**（硬性，不进打分）：
- 量比 < 1.2 且 OI 变化率 < +1% → 信号直接不发 / 强制降级 <50 分
- OI 同向原则：价涨+OI增=真突破；价涨+OI减=反弹，信号降级

**4️⃣ 风控刹车**：
- **费率动态判断**（每 4h 刷新，看 24h 变化率不看绝对值）：
  - 危险档：24h 费率飙升 ≥3 倍 且 当前 >0.03% → 多头拥挤，做多信号拦截 + 触发【多头拥挤预警】到出场引擎
  - 稳定高位档：绝对值高(0.03%~0.1%) 但 24h 波动 <±30% → 允许入场，仓位系数 ×0.7
  - 正常档：其余 → 正常仓位
- **清算距离**：现价距最近清算密集区 ≥ 波动率系数×ATR
- **波动率自适应系数**（布林带宽 BW=(上轨−下轨)/中轨，对比过去100根K线中位数）：
  - 带宽收缩（BW < 中位×0.75）→ 系数 1.0（紧止损）
  - 带宽扩张（BW > 中位×1.5）→ 系数 2.0（宽止损）
  - 正常区间 → 系数 1.5
  - 清算距离、止损距离、回踩容差全部跟随同一系数联动
- **盈亏比** ≥ 2（止损距离与第一止盈目标计算）

**5️⃣ K线形态硬刹车**（纯价格行为，信号输出前最后关卡）：
- 入场前强制等待：当前 15m K线收盘
- 条件：收盘价 > 前一根 15m K线最低点（不破前低）且 实体 ≥ 影线（排除长上影诱多）
- **"旱地拔葱"例外**（同时满足可豁免等待，直接市价入场）：
  ① 信号触发时当前 15m K线已运行 >10 分钟（剩余 ≤5 分钟）
  ② 现价已突破前高 ≥ 1.5×ATR（远超最低确认标准）
  - 注意：豁免仅限 K线形态检查，量能/费率/宏观等硬条件不豁免

**6️⃣ 宏观静默期**：
- 触发事件：美国 CPI / 非农 / FOMC 利率决议 / 鲍威尔讲话（内置固定表 + 用户手动维护）
- 窗口：公布前 15 分钟 ~ 公布后 15 分钟（共 30 分钟）
- 动作：暂停所有新开仓（含 30% 加仓单）；已有持仓不受影响，出场预警正常运转

**7️⃣ 仓位与执行**：
- 仓位公式（固定风险模型）：`计划仓位 = (总资金 × 单笔风险比例 2%) ÷ 止损距离百分比`
- 执行：① 确认通过 → 市价入场 70% 计划仓位；② 剩余 30% 挂限价单：前一根 15m 阳线 50% 回撤位
- 加仓单失效规则：入场后 3 根 15m K 线（45 分钟）未成交自动撤单；价格先触及初始止损则立即撤单
- 费率档位系数：正常 ×1.0 / 稳定高位 ×0.7

**8️⃣ 持仓管理（止损三段式演化）**：

| 阶段 | 触发条件 | 止损位置 |
|------|---------|---------|
| 一、初始 | 开仓后立即 | 带宽扩张档 2.0×ATR |
| 二、保本 | 浮盈 ≥ 1.5×ATR | 上移至 开仓价+手续费 |
| 三、跟踪 | 浮盈 ≥ 3×ATR | 切换 EMA21 动态跟踪：1h K线收盘跌破 EMA21 → 止盈离场 |

- 时间止损：入场后 2×ATR 时间周期内未走出 1×ATR 利润 → 建议离场
- 相关性检查：同方向多币种持仓（如 BTC+ETH 同多）→ 风险叠加提示

**9️⃣ 信号生命周期**：
- 有效期：发出后 3 根 15m K 线未成交 → 自动作废
- 冲突规则：同币 5m 与 15m 方向冲突 → 小周期服从大周期，标记冲突提示

**🔟 出场预警引擎**（持仓中平行运行，阈值比入场宽松）：

| 预警类型 | 触发条件 | 建议动作 |
|---------|---------|---------|
| 技术反转 | 15m EMA7 下穿 EMA21 / 1h 跌破 EMA21 / RSI 顶背离 | 平仓或减 50% |
| 费率突变 | 24h 费率飙升 ≥3 倍（多头拥挤） | 减仓 + 警惕瀑布 |
| 止损逼近 | 价格距当前止损 < 0.5×ATR | 关注，准备执行 |
| 阶段切换 | 触发保本 / 进入 EMA21 跟踪 | 提示止损已上移 |
| 时间止损 | 入场 2×ATR 周期未走出 1×ATR 利润 | 建议离场 |

## 5. 置信度评分表（加权打分）

| 维度 | 权重 | 计分项 |
|------|------|--------|
| 市场环境 | 20 分 | BTC 方向 12 + 市场宽度 8 |
| 趋势方向 | 30 分 | 价格结构 12 + EMA 体系 10 + MACD 8 |
| 时机确认 | 25 分 | 扳机级别 15（A级满分）+ RSI 位置 10 |
| 情绪风控 | 25 分 | 费率 ROC 15 + 清算距离 10 |

**硬性关卡（不进打分，直接否决）**：量能否决、K线形态、ADX 门、市场环境门、宏观静默。

- ≥70 分 → 🟢 强信号，推荐执行
- 50~69 分 → 🟡 弱信号，仅提示观察
- <50 分 → 不输出

## 10. 非功能需求

- **API 预算**：粗筛 40 weight/分钟 + 精扫约 240 weight/5分钟 ≈ 消耗上限额度 15% 以内
- **可靠性**：币安接口网络重试（指数退避）、断线自动重连、数据缓存防抖
- **数据存储**：SQLite（信号历史、持仓、费率历史、宏观日历）
- **时区**：所有时间显示本地时区，内部存储 UTC
