### 2. 精扫性能优化（A-E 五方案全部落地）
| 方案 | 内容 | 效果 |
|---|---|---|
| A 并发化 | Semaphore(4) + 滚动权重预算 1800/min（官方 2400 的 75%）+ ccxt 本地节流 + 429 长退避(30/45/60s) | 精扫 **480s → 98.8s** |
| B 分级缓存 TTL | 4h→900s、1h→600s、15m→300s、5m→120s | 缓存命中轮大幅提速 |
| C 监控轻量化 | 监控只拉 limit=2 根 K 线；**缓存 key 含 limit 维度**（ohlcv:sym:tf:limit），2 根数据不会污染精扫 300 根缓存 | 权重 1/请求 |
| D 僵尸币过滤 | 24h 成交额 < 100 万 USDT 不入池（自选除外） | 减少无效精扫 |
| E K线根数分级 | 4h→120、1h→200、15m/5m→300（EMA55 余量充足） | 减少传输与计算 |

- 实测：首轮（缓存空）105.2s/173 币 → 后续轮 **28.2s**/174 币，提速约 17 倍，全程 **0 次 429**
- 验证「我踏马来了」24h 成交额 244 万 U，过滤正确放行（非僵尸币）
